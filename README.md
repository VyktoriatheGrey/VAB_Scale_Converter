# VAB_Scale_Converter
A tool to convert visual breast measurements on a ref sheet into "real world" sizes. The VABS chart is a fictional cup scale that extrapolates from real world bra sizes to accommodate hyper and macro breasts.

While this uses real world bra and breast data to create a sizing chart for pure breast size, it is fictional and intended for entertainment uses. The scale extends from A to ZZZ cups, or breasts that are 10.6cm/4.17in to 155.5m/510ft in diameter—enough to cover many macro and hyper sizes! It is important to understand that this is *NOT* a bra size calculator, but a *breast* size calculator. However, given the nature of macro and hyper breasts (as they are usually attached to gigantic body sizes), one can easily use this as an "approximate" bra size (noting that it does not include underbust or ribcage measurements like real world bra sizes do).

There is an option to take a real world bra size (US/European, UK/AUS, and Japanese) and convert it to the VABS scale.

Measurements from a ref sheet are assumed to be of a character that is standing upright and either a front-view or a side-view of the OC. You can measure the character from your ref sheet using a ruler (inches and cm) or pixels (using the correct program). You will need to know how tall your character is "in-universe," which I assume is one of, if not the only, stat 99.99% of creators figure out for their OC.
